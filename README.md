# Western Multi-Family Renovation (WMFR) - Landing Page

A high-performance, responsive landing page for Western Multi-Family Renovation featuring occupied CAPEX remodel services, interactive project quote modal, and a cinematic logo intro animation matching Remotion motion dynamics.

## Features
- **Cinematic Vector Intro**: Real-time 60fps sunrise, 3D extruded typography, spring-eased vegetation, and smooth docking to the header navbar.
- **Occupied Unit Remodeling Showcase**: Highlights 100–1,200+ unit high-velocity occupied renovation capabilities (lead contractor for AVA Toluca Hills).
- **Interactive Modals**: Instant quote request form with scope selector and direct calling shortcuts.
- **Zero-Config Vercel Deployment**: Static files ready to deploy directly on Vercel, Netlify, or any static host.

## Tech Stack
- HTML5 / CSS3 (Modern Flexbox/Grid, Glassmorphism, CSS Custom Properties)
- Vanilla JavaScript (High-performance RAF animation loop, Bezier easing, GPU compositing)
- SVG Vector Graphics
